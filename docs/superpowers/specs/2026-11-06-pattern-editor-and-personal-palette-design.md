# 图纸编辑体验与个人拼豆颜色库设计

日期：2026-11-06

## 目标与范围

修复图纸缩略时色号文字盖住颜色的问题；每 5 格增加贯穿的分组线且相册导出保留；调整编辑页为「轻奶油」风格；增加左右镜像和调整工具栏顺序；在 App 根级增加个人颜色库 Tab，新建图纸时可使用最新库存。保留现有图纸生成算法、其他配色预设、相册导出的色号／刻度／图例和图纸列表缩略图的现有行为。

## 画布与导出

- 编辑画布继续使用 SwiftUI Canvas，不为每个格子创建独立视图。基于 **屏幕实际单格边长**（现有 `baseCellSize × scale`）控制色号：单格边长不足约 18 pt 时不画色号；达到阈值后，以能完整放入格子为条件显示，字号在可读范围内随格宽增长并设上限，不允许文字溢出相邻格。缩小到全图时应只看到原始颜色与线条，不出现密集文字。放大时实时更新，无需额外按钮；色号对比色和高亮过滤保持现状。
- 在图纸坐标系的第 5、10、15……格后（即网格坐标 `5 × cellSize` 等）画连续水平和垂直实线，贯穿当前图纸的宽／高，非 5 的倍数尺寸也正确截断。线条在豆色及文字之上绘制，不盖住尺标区；使用比普通单格边框更明显的中性深色，编辑画布使用屏幕像素尺度附近的线宽，避免在缩放时过粗。空白／透明格上也能看到分组线。若需要保留现有细格线，缩略时细线不能压过豆色；分组线优先清晰。采用小的纯几何辅助逻辑共享边界位置，具体绘制仍由画布和导出分别完成。
- 相册保存继续调用独立的 `PatternExportRenderer`，保留默认 24 px 单格、色号、尺标、颜色图例、透明格及现有输出布局，仅叠加相同位置的分组线；不受当前编辑缩放或是否隐藏屏幕色号影响。项目列表缩略图依旧保持纯色、不加线和色号。

## 编辑页外观与操作

- 只修改截图所示的编辑页周边：淡奶油白背景、浅杏粉的色卡区域、暖色系工具栏和柔和玫瑰粉选中状态；真实豆色、颜色图例及相册输出不套滤镜。画布本身保持清晰的白底；空格和缩略图处理不因外观配色变化而重写。
- 工具栏从左到右先放「调整图纸大小」，再放画笔、橡皮擦、吸管和新「左右镜像」按钮，撤销／重做保留在右侧；各工具提供清楚的无障碍标签与选中状态。尺寸调整仍使用现有二次确认和重新生成流程。
- 左右镜像直接把当前 `BeadGrid` 每行的颜色顺序翻转；不改变尺寸、源照片或 MARD 色号。操作前记录一次历史，操作后更新编辑画布并沿用现有延迟保存路径更新持久化图纸和列表缩略图；撤销／重做各作为一次完整操作。导出保存的是当前镜像后的图纸。处理中不可再次触发镜像。

## 个人颜色库与导航

- App 根层使用「图纸」「我的颜色」两个 Tab；现有图纸列表、新建／编辑导航留在「图纸」Tab 内，切 Tab 不触发图纸数据变更。「我的颜色」Tab 用色号卡片展示当前库存，可从内置 `MardPalette.allColors` 中按色号搜索／选择尚未拥有的颜色，支持移除已有颜色；重复添加无效，不支持自定义色值或改动内置颜色定义。
- 本机持久化的是 **所拥有的色号集合**，不是颜色 RGB 副本。首次安装／旧版升级、尚无用户记录时，以现有 `MardPalette.standard221` 的全部色号初始化一次；明确删除至空库后仍保持空，不再自动补回。读取时以 `allColors` 为准解析，忽略无效色号并保持稳定的色卡排序。保存失败时应反馈用户而不是假装操作成功；本次不增加云同步或多套库存。
- 生成设置页的「我的」选项显示实时库存数量。用户点击生成时才从当前库存取得颜色快照并传入现有生成流程；其他预设仍走既有采样／全集逻辑，历史图纸读取仍使用全集解码，不因库存变化而失色。如果「我的」库存为空，生成按钮不可用并给出前往「我的颜色」添加颜色的提示；选用其他预设仍可生成。设置页正打开时从另一 Tab 更改库存，返回后数量与生成限制能刷新。
- 编辑页的「重新生成并调整尺寸」无论原图纸使用哪种预设，都以用户**确认重新生成当时**「我的颜色」库的最新完整颜色集合为新图纸调色板。空库时不执行生成并提示先添加颜色；处理或持久化失败时保留原图纸并给出失败提示，成功后才替换网格、缩略图和撤销历史。

## 数据流与边界

- 库存存储组件提供 `loadCodes / add / remove / resolvedColors` 等语义，负责首次初始化及空集合与未初始化的区别。UI 只使用库存状态，不直接修改 `MardPalette.standard221`；生成模型不长期缓存「我的」固定色表。
- 画布显示规则和每 5 格边界计算独立于 SwiftUI 手势与绘图上下文，便于测试；网格的数据变换独立于按钮动作，确保 1×N、N×1、非 5 倍数、背景空格都可处理。
- 控制风险：本次不修改现有 SwiftData `BeadProject` 结构或旧项目编码格式；仅新增独立库存偏好数据。色号表若发生调整，应安全忽略已失效色号，不损坏已有图纸。

## 验收与测试

1. 生成并打开大图纸，全图适配时无密密麻麻的色号；捏合放大后在足够大的格子中清楚出现色号，缩回后消失；横竖每 5 格的线连续贯穿，包括空格。
2. 相册导出保留旧有的色号／尺标／图例和尺寸，额外有分组线；导出不随着编辑画布缩放而改变。列表缩略图仍只有色块。
3. 左右镜像后肉眼可见左右反转，保存／重新打开仍生效；撤销再重做正确。工具栏尺寸按钮位于最左。
4. 新安装或旧数据升级时「我的颜色」预填现有色号；添加、删除及重启后仍正确；删空后不会恢复；新建图纸「我的」数量即时更新，生成仅使用当时库存，其他预设和历史图纸不受影响。
5. 单元测试覆盖分组线坐标、色号阈值／适配、镜像与撤销历史、库存初始化／空库／增删／解析；重新生成时验证使用最新库存、空库及失败保留原图；现有核心及持久化测试继续通过，编辑和新建主流程 UI 测试按需扩展。对绘制结果和新配色进行 iOS 模拟器手动检查。

# 图纸尺寸重生期间的编辑锁定设计

日期：2026-11-10

## 问题与目标

编辑页调整尺寸开始时会同步保存当前网格并取消原有延迟保存，然后在后台运行生成。当前 `isRegenerating` 只阻止部分按钮；画布拖动、画笔工具切换、色卡、撤销和重做仍可操作。撤销/重做会创建新的延迟写任务，在后台生成完成并保存新网格以后可能再把旧网格写回持久化项目。用户要求修复并在检查无误后提交，现有颜色匹配/镜像/相册导出语义不变。

## 设计

- 重生时全编辑区保持可见，但输入被锁：画布绘制/擦除/取色、颜色卡选择、工具切换、撤销/重做、镜像、再调整尺寸及相册保存不可启动；导航返回仍可用。除 `.disabled` 视觉状态外，所有会修改网格的 handler 在入口 `guard !isRegenerating`，防止已开始的拖动手势在遮罩出现后继续改色；画布 `onCellTouched` 闭包捕获调用时的最新状态。
- 一次重生确认时先拒绝空库存、不可解码原图和未载入网格；同步保存当前编辑格，如果保存失败回滚并显示错误、不启动后台任务。开始前 `cancelPendingSave()`，设 `isRegenerating = true`；从此直到提交成功/失败后置 `false`，禁止再次排队旧网格。
- 成功：先保存新的尺寸和缩略图，再更新 UI 网格，重置历史，一次性恢复操作。失败（解码/生成/SwiftData 保存）：旧网格/历史保留并显示具体错误，若 SwiftData 抛错则回滚。离开页面时若正在重生不调用旧格 `saveImmediately`，已同步保存的旧格不会丢，后台结果提交后状态一致；任务不另行取消。导航返回后恢复到项目列表可在完成后重新打开最新保存项目。
- 不新增持久化字段；不更改图纸内容和颜色算法。之前确认的 opaque alpha 快速退出独立保留。

## 验收

1. 用 UI 自动化创建样图，作一次可撤销的镜像/涂色，选新尺寸并确认重生。在再生成进度期间断言画笔/色卡/撤销/重做禁用，手势入口不会修改格；导出按钮同样禁用。待完成后撤销/重做历史清空，导出可用；退出重新打开读到新尺寸，没有待保存旧格覆盖。
2. 定向测试验证拖动在重生状态的 handler 不生效，以及 `DebouncedGridSaver.cancelPendingSave` 真正阻止旧快照写回；模拟失败流程验证旧项目仍可打开并拥有原尺寸/历史。
3. 完整 iOS UI、BeadCore（含 seeded goldens）、BeadPersistence 测试与 `git diff --check` 通过，才提交当前功能分支；不推送，除非用户另提要求。
